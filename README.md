# documento-projeto-gestao-orcamentos
Este repositório reúne toda a documentação produzida na disciplina MSI I, incluindo requisitos, diagramas e protótipo do sistema web para gestão de orçamentos em serviços de gesso.

## Visão geral
Este repositório contém os artefatos de análise e projeto do sistema web para divulgação de serviços de gesso e simulação de orçamentos, desenvolvido ao longo de MSI I.
O sistema contempla um frontend em React, backend em ASP.NET Core e banco de dados relacional para suporte às funcionalidades de catálogo e administração.

## Estrutura do repositório
`requisitos/`: especificação de requisitos funcionais e não funcionais, casos de uso e regras de negócio.

`diagramas/`: diagramas UML (casos de uso, classes, componentes, atividades, sequência e ER) em PlantUML e imagens.

`bd/`: modelo conceitual, lógico e scripts de criação de tabelas do banco de dados.

`outros/`: materiais complementares (banner e apresentações).

## Requisitos
O diretório `requisitos/` concentra a especificação de alto nível do sistema, incluindo visão geral, atores, cenários e requisitos priorizados.
Também inclui a descrição dos fluxos principais, qu são, principalmente, a simulação de orçamento pelo cliente e o gerenciamento de serviços pelo administrador.

## Diagramas
No diretório `diagramas/` estão os diagramas UML que apoiam o entendimento da solução.
Eles representam casos de uso, atividades, sequência, classes, componentes e modelo entidade-relacionamento do sistema.
